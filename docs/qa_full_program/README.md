# QA funcional y visual integral v1

QA-1 combina crawler autenticado, análisis de controles renderizados, regresión funcional y revisión visual sobre una base sintética aislada. Alcance: 395 declaraciones operativas, 110 GET seguras, 199 templates y todos los dominios del ERP certificado.

Hallazgos principales: pérdida del tenant en el shell de ciertas vistas, dashboard financiero sin layout, assets sin versionado y cinco paths duplicados. Las correcciones conservan permisos, servicios y compatibilidad pública.
