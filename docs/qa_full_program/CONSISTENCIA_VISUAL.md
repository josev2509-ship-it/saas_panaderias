# Consistencia visual

Enterprise Shell global, SEDL, breadcrumbs, headers, tablas, formularios, botones, badges y estados vacíos se cargan desde `base.html`. QA1 añade layout para `metric-grid`, `metric-card` y `module-links`, además de límites seguros para la identidad de usuario en topbar.

La hoja y el script de convergencia usan `?v=qa1` para evitar caché obsoleta. No se cambiaron colores de negocio ni KPIs.
