# Evidencia visual

Treinta capturas en `evidencia/`: desktop 1440×900 y móvil 390×844 para login, dashboard, clientes, Cliente 360, pedido, factura de venta, proveedores, orden de compra, recepción, inventario, producción, CxC, CxP, contabilidad y reportes.

La sesión usa una base temporal nueva, empresa ficticia y generadores certificados; no contiene datos reales. La auditoría visual detectó y permitió corregir dos errores de render P2P y un overflow de reportes antes de conservar las capturas finales.
