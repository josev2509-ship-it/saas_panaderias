# Datos demo

El comando `generar_demo_ready --empresa ID` orquesta los seis generadores certificados existentes para configuración comercial, O2C inicial, CRM, O2C completo, P2P y administración.

Propiedades verificadas por pruebas existentes: `dry-run`, idempotencia, aislamiento por empresa y ausencia de datos reales. Inventario/producción y operaciones usan las entidades ya producidas por menús, pedidos, recepciones y movimientos; no se fabrican KPIs.
