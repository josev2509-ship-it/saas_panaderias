# Riesgos

- Las rutas heredadas conservan markup heterogéneo; la capa progresiva depende de primitivas HTML semánticas.
- Tablas anchas usan scroll interno en móvil para preservar datos.
- Pantallas sin ruta real se excluyen del guion, evitando promesas funcionales falsas.
- Los datos demo dependen de los seis generadores existentes y deben ejecutarse en una empresa de demostración aislada.
