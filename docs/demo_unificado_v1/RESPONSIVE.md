# Responsive

Tamaños objetivo: 1440×900, 1366×768, 1024×768, 768×1024 y 390×844.

La capa D1 limita el contenido al shell, normaliza grids Bootstrap heredados, permite scroll dentro de tablas y evita overflow global. Evidencia visual en `evidencia/`.

Resultado: 15 familias sin overflow global en los cinco tamaños. Se verificaron 1440×900 y 390×844 mediante captura; 1366×768, 1024×768 y 768×1024 mediante medición DOM pantalla por pantalla.
