# API interna
`comercial/api/` expone DTOs inmutables, nunca QuerySets. Contratos: obtener cliente/crédito/exposición; resolver precio/simular descuento; crear/convertir cotización; crear/consultar pedido/programación/disponibilidad; solicitar/liberar reserva; crear despacho/conduce/entrega; emitir factura/notas; consultar CxC; registrar cobro/promesa/factoring; calcular comisión. Comandos reciben OperationContext e idempotency_key, retornan DTO+referencia y declaran ValidationError/PermissionDenied/Conflict; consultas reciben empresa+actor. Toda mutación audita y publica evento versionado.
