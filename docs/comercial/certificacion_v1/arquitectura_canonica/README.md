# Arquitectura canónica Comercial Enterprise v1
Contrato previo a implementación. Ciclo: CRM → preventa → pedido → disponibilidad → entrega → factura → CxC → cobro. INABIE es extensión opcional. Aplican OperationContext, Core numbering, EventBus, auditoría, documentos, Workflow y API interna; ningún módulo escribe modelos ajenos.
