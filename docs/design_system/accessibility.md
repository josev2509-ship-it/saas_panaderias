# Accesibilidad

- Mantenga foco visible; nunca use `outline:none` sin reemplazo.
- Todo campo necesita `label`.
- Iconos no sustituyen texto crítico.
- Use `aria-current`, `aria-expanded`, `aria-controls` y `aria-live`.
- Los modales llevan `role="dialog"` y `aria-modal`.
- Los estados incluyen texto además de color.
- Imágenes informativas necesitan texto alternativo.
- Escape cierra navegación y modales.
- Respete `prefers-reduced-motion`.
