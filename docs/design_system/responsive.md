# Responsive

Anchos de referencia: 360, 390, 768, 1024, 1366 y 1920 px.

- Hasta 768 px el sidebar se convierte en panel superpuesto.
- KPIs pasan de cuatro a dos y luego a una columna.
- Formularios y detalles pasan a una columna.
- `.ds-responsive-table` transforma filas en tarjetas usando `data-label`.
- Botones mantienen al menos 42–44 px de altura táctil.
- Los modales respetan el alto visible.

Valide que no existan enlaces fuera del viewport ni encabezados truncados.
