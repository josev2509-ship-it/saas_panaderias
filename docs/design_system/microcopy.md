# Microcopy

Tono: claro, breve, profesional y accionable.

- Indique qué ocurrió y qué puede hacer el usuario.
- Use verbos concretos: Guardar, Aprobar, Reintentar, Cancelar.
- Explique impacto antes de acciones críticas.
- Evite “Error”, “Inválido” o códigos técnicos sin contexto.
- Éxito: “El pedido fue aprobado y quedó listo para preparación.”
- Error: “No fue posible guardar. Revise los campos marcados e intente de
  nuevo.”
- Vacío: explique por qué no hay datos y sugiera una acción real.
