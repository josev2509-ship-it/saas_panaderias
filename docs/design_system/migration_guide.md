# Guía de migración

1. Extienda `base.html`.
2. Elimine bloques de estilos duplicados.
3. Reemplace encabezados por `.ds-page-header`.
4. Use tarjetas, filtros, tablas y estados centrales.
5. Añada vista móvil o `.ds-responsive-table`.
6. Proteja envíos críticos.
7. Compruebe permisos y empresa.
8. Pruebe rutas, mensajes, vacíos y tamaños de referencia.

Pilotos v1.0: Inicio, Centro Técnico, clientes, detalle de cliente, pedidos,
detalle de pedido, inventario y gestión de conduces.
