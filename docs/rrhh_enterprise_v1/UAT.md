# UAT
UAT local autenticada realizada con tenant y credenciales sintéticas efímeras. Se recorrieron 20 rutas: dashboard, empleados, ingreso, Empleado 360, contratos, documentos, cursos, amonestaciones, vacaciones, licencias, ponches, corrección, horas extra, nómina, detalle, prestaciones, TSS, salidas, reingreso y reportes.

Las 11 pantallas críticas pasaron 55 combinaciones en 1440×900, 1366×768, 1024×768, 768×1024 y 390×844. Resultado final: `scrollWidth == clientWidth`, 0 errores JavaScript y 0 assets críticos 404.
