# Datos demo
`python manage.py generar_demo_rrhh --usuario <usuario>` crea por tenant identidades DEMO, activos/inactivos, contratos, documentos, cursos, vacaciones/licencias, disciplina, ponches/incidencias, horas extra, nómina, prestaciones, salida/reingreso y TSS.

La doble ejecución UAT mantuvo conteos estables y no duplicó registros. No usa datos personales reales ni porcentajes/fórmulas legales inventadas.
