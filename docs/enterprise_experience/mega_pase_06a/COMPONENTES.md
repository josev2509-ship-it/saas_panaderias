# Componentes

La biblioteca incluye KPI Card, Module Card, Alert Card, Timeline, Empty State, Status Badge/Chip, Enterprise Table, Filter Bar, Tabs, Breadcrumbs, Page Header, Toolbar, Form Section, Sticky Actions, Modal, Drawer, Toast, Skeleton, Loader, Wizard Stepper, Pagination y Export Menu.

Los componentes aceptan contenido y URLs; no ejecutan lógica de negocio. Las variantes válidas usan prefijo `ds-` y tonos semánticos.
