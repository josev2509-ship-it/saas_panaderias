# Enterprise Experience Foundation v1

Capa visual transversal de SASTRE ERP. Este pase reorganiza navegación, shell, dashboard y patrones de interfaz sin cambiar modelos, servicios, APIs ni reglas certificadas O2C/P2P.

## Alcance

- Shell adaptable con sidebar persistente, topbar, contenido y footer.
- Dashboard ejecutivo basado exclusivamente en el contexto ya disponible.
- Componentes, tablas y formularios normalizados por CSS y templates.
- Accesibilidad y responsive base.
