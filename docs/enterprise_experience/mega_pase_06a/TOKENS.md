# Tokens

Fuente única: `conduces/static/design_system/css/tokens.css`.

- Color: primary, secondary, success, warning, danger, info, neutral, background, surface, border y texto.
- Espacio: 4, 8, 12, 16, 24, 32, 40 y 48 px equivalentes.
- Radios: small, medium y large.
- Sombras: subtle, card, dropdown y modal.
- Tipografía: escalas xs a 3xl; KPI usa escala fluida y números tabulares.

No deben agregarse valores repetidos en CSS de módulo cuando exista un token equivalente.
