# E2E final

El recorrido cubre solicitud, sourcing, orden, recepciones parciales y total vía InventoryEngine, factura/CxP, notas, anticipos, retenciones, pagos, asientos, extracto sintético, previsualización, importación confirmada, matching por referencia y monto/fecha, conciliación y desconciliación separada. Incluye EventBus, auditoría, reintentos, idempotencia, error forzado, rollback y reanudación de wizard.
