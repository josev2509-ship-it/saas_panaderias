# Retenciones de proveedor

Se soportan ITBIS, ISR y tipos configurables, por factura u orden de pago. La tasa es un dato configurado por el operador y no una constante legal. Cada aplicación conserva base, tasa, monto, saldo y asiento. Los certificados contienen una huella SHA-256 verificable, no datos bancarios. Aplicación y reversión son transaccionales, auditables e idempotentes.
