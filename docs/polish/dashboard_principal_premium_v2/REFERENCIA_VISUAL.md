# Referencia visual

Fuente: `02_REFERENCIA_VISUAL_APROBADA.png` del paquete de reemplazo.

Rasgos canónicos: sidebar navy compacta; topbar blanca de baja altura; cuatro KPI; composición 6/3/3 para producción, atención y producto de mañana; segunda fila con actividad, seis accesos compactos y resumen financiero; densidad suficiente para mostrar la composición principal en 1440×900.

La implementación no reutiliza el Hero blanco, las seis tarjetas de acción sobredimensionadas ni el gráfico vacío gigante de la pantalla rechazada.
