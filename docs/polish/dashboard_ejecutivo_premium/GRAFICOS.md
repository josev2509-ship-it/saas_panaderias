# Gráficos

Los dos paneles iniciales son ventas/cobros y compras/pagos. Producción y aging permanecen diferidos hasta seleccionar su tab. Un canvas sólo se emite cuando hay datos; Chart.js conserva leyendas accesibles y tooltips formateados.

El selector documenta el período activo; esta versión certificada calcula el mes actual y no simula series inexistentes.
