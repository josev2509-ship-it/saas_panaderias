# Responsive

- Escritorio: Hero, KPIs, atención, gráficos, actividad, eventos y acciones.
- Tablet: KPIs en cuatro columnas y alertas en dos.
- Móvil: Hero, alertas, KPIs deslizables, acciones, actividad, gráficos y eventos.
- Los botones y tabs permiten desplazamiento horizontal sin cortar contenido.
