# Riesgos

- La búsqueda del command bar actúa sobre la página visible; los filtros de servidor siguen siendo la fuente para conjuntos completos.
- La persistencia de columnas no se lleva al servidor porque no existía infraestructura certificada; la densidad persiste sólo durante la sesión.
- Las rutas registradas como `NO APLICA` no deben crearse dentro de este pase.
- Las pantallas financieras de reportes no son listados y se mantienen fuera del patrón para no inventar tablas.
