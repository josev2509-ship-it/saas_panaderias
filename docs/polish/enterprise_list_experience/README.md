# Enterprise List Experience v1

Patrón visual reutilizable para las listas canónicas prioritarias del ERP. Unifica encabezado, command bar, tabla, búsqueda local, columnas, densidad, estados vacíos y responsive sin cambiar reglas, permisos, rutas ni servicios O2C/P2P.

La propagación se realiza en templates canónicos compartidos y específicos; las pantallas sin ruta de lista real se registran como `NO APLICA`.
