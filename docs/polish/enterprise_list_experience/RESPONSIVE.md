# Responsive

Validado en 1440×900, 1366×768, 1024×768, 768×1024 y 390×844. En las diez familias y en representantes O2C/P2P se comprobó `scrollWidth == clientWidth`.

En móvil el encabezado y command bar se apilan, las tablas eliminan el ancho mínimo global y cada celda muestra su etiqueta. Los filtros y acciones siguen accesibles.
