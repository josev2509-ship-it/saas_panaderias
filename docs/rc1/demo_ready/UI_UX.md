# UI y UX

Las pantallas críticas conservan Enterprise Shell, sidebar, topbar, encabezados, breadcrumbs, botones, cards, tablas y estados. Se corrigió la propagación de acciones sticky a formularios dentro de tablas, el render de listados financieros y la cabecera contable móvil.

Los activos visuales modificados usan versionado RC1 para invalidar caché legacy.
