# INABIE E2E

La demo incluye centro operativo, menú del día, conduces en estados representativos, producto facturable, comprobante B15 y factura INABIE emitida con detalle. Los registros se crean por empresa con claves estables.

Las relaciones diaria/general se demuestran desde la gestión de conduces y sus acciones de PDF; no se creó una pantalla paralela.
