# Menú lateral

El contrato común se sirve desde el shell base. Las rutas Inicio, Workspace, Comercial, CRM, Compras, Inventario, Producción, Contabilidad y Workflow mostraron `.app-sidebar` y `aria-label="Navegación principal"`.

Los grupos de navegación se conservan en el mismo orden entre dominios. Las cuatro pantallas INABIE corregidas ahora heredan `base.html` y ya no declaran un `<aside>` independiente.

Resultado: consistente en las 55 combinaciones visuales auditadas.
