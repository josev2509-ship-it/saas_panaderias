# Incidencias restantes

No quedan incidencias bloqueantes identificadas dentro del alcance RC1 Pase A.

Observaciones no bloqueantes:

- Los dos alias O2C deben conservar pruebas explícitas mientras exista compatibilidad histórica.
- Las plantillas de impresión/documento no deben forzarse dentro del shell interactivo.
- Los inventarios deben regenerarse cuando cambie el resolver o el árbol de templates.
