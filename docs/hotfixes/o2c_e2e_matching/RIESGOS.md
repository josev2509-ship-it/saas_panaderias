# Riesgos

El hotfix no cambia comportamiento productivo. La prueba conserva fechas fijas para representar un escenario histórico determinista; si el escenario cambia, las fechas del cobro, extracto y conciliación deben mantenerse coherentes.

Riesgo residual bajo: el algoritmo productivo mantiene su tolerancia de ±3 días y su prioridad por referencia exacta sin cambios.
