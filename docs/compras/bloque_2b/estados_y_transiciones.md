# Estados y transiciones

BORRADOR pasa a LISTA_PARA_ENVIO o CANCELADA. LISTA puede volver a BORRADOR, iniciar EN_APROBACION o cancelarse. Workflow lleva EN_APROBACION a APROBADA, RECHAZADA o DEVUELTA. La devolución admite corrección versionada y reapertura. APROBADA, RECHAZADA, CANCELADA y CERRADA son finales en este bloque.
