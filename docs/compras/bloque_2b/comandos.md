# Comandos

Disponibles: `configurar_solicitudes_compra`, `verificar_integridad_solicitudes`, `listar_solicitudes_bloqueadas`, `recalcular_solicitudes`, `diagnosticar_workflow_solicitudes` y `verificar_documentacion_solicitudes`. Son diagnósticos no destructivos; la configuración es idempotente y el recálculo soporta `--dry-run`.
