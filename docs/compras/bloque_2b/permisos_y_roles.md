# Permisos y roles

El modelo define permisos explícitos para enviar, cancelar, duplicar, corregir, consultar historial, ver todas, exportar, administrar, documentos y cambios de preparación. `configurar_solicitudes_compra` crea de forma idempotente Administrador, Solicitante, Comprador, Supervisor, Auditor y Consulta sin retirar permisos existentes.
