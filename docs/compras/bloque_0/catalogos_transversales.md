# Catálogos transversales

Se implementan moneda ISO global con habilitación empresarial, condición de
pago, unidad y conversión, almacén, centro de costo, impuesto mínimo y tipo de
compra. Unicidades, principales y bases se controlan por empresa.

No hay motor de tasas, presupuesto ni tributación completa. Los campos
heredados continúan vigentes hasta una adopción planificada.
