# Riesgos

- Los gráficos dependen de Chart.js CDN solo cuando existen datos; sin datos se muestra empty state.
- La calidad narrativa depende de ejecutar y verificar el pipeline sobre una empresa demo aislada.
- Las vistas 360 muestran únicamente información disponible en contratos actuales.
- La UAT visual manual no está sustituida por pruebas estructurales.
- No ejecutar el generador sobre tenants con datos reales.
