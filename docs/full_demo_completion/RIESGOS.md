# Riesgos

| Riesgo | Nivel | Mitigación |
|---|---|---|
| O2C demo sin población full | Medio | estado vacío premium; no inventar lógica |
| Alias y precedencia de rutas | Bajo | literal de reportes antes del conversor; crawler normaliza alias |
| CSS inline legado | Bajo | capa global; limpieza posterior aislada |
| Crawler no ejecuta POST/PDF | Esperado | suite funcional por dominio |
| Costo de inicialización de base de pruebas | Medio | crawler separado y `--keepdb` en iteración local |
