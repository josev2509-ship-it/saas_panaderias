# Guía de demo completa

1. Iniciar sesión y presentar dashboard, workspace, alertas y búsqueda.
2. Abrir Comercial, CRM, cliente 360, pedidos y O2C.
3. Mostrar Conduces/INABIE: búsqueda, centros, menú, calendario y facturación.
4. Recorrer Compras: proveedor, solicitud, expediente/RFQ, orden, recepción y finanzas P2P.
5. Abrir inventario, kardex/recetas y planificación/órdenes de producción.
6. Cerrar con CxC, CxP, factoring, contabilidad y reportes.

No ejecutar transiciones irreversibles durante la demo. Si O2C no tiene datos, explicar el estado vacío sin simular operaciones inexistentes.
